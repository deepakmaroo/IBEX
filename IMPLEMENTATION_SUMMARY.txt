VERSIONING STRATEGY
=============================================================================

Frontend: @ibex/frontend@X.Y.Z (npm semver)
Backend:  ibex@X.Y.Z (pip PEP 440)

Independent but compatible:
- Major versions align for breaking changes
- Minor/patch can diverge
- API versioning ensures compatibility
